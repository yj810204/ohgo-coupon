# 물고기 레벨 업데이트 가이드

이 문서는 Firebase의 물고기 데이터에 레벨 필드를 추가하는 방법을 설명합니다.

## 변경 사항 개요

1. 물고기 데이터에 `level` 필드 추가 (1-5 범위)
2. 공통 거리 및 포인트 값 설정 (게임 설정 화면에서 관리)
3. 물고기 레벨에 따라 거리, 시간, 포인트가 자동으로 계산됨

## 물고기 레벨 추가 방법

Firebase 콘솔에서 다음 단계를 따라 물고기 데이터에 레벨 필드를 추가하세요:

1. Firebase 콘솔에 로그인
2. 프로젝트 선택
3. Firestore Database로 이동
4. `fishes` 컬렉션 선택
5. 각 물고기 문서에 `level` 필드 추가:
   - 쉬운 물고기: `level: 1`
   - 보통 물고기: `level: 2` 또는 `level: 3`
   - 어려운 물고기: `level: 4` 또는 `level: 5`

## 레벨별 특성

각 레벨에 따른 특성은 다음과 같습니다:

| 레벨 | 난이도 | 거리 범위 (기본값 기준) | 포인트 범위 (기본값 기준) | 시간 |
|------|--------|-------------------------|--------------------------|------|
| 1    | 매우 쉬움 | 40-50% | 40-60% | 거리의 50% |
| 2    | 쉬움     | 50-60% | 50-70% | 거리의 50% |
| 3    | 보통     | 60-70% | 60-80% | 거리의 50% |
| 4    | 어려움   | 70-80% | 70-90% | 거리의 50% |
| 5    | 매우 어려움 | 80-100% | 80-100% | 거리의 50% |

## 게임 설정 방법

관리자 화면의 '낚시 게임 설정' 섹션에서 다음 값을 설정할 수 있습니다:

1. **공통 거리**: 모든 물고기에 적용되는 기본 거리 값 (기본값: 50)
2. **공통 포인트**: 모든 물고기에 적용되는 기본 포인트 값 (기본값: 1000)

이 값들은 물고기의 레벨에 따라 자동으로 조정됩니다.

## 주의 사항

- 기존 물고기 데이터에 레벨을 추가하지 않으면 기본적으로 레벨 1로 처리됩니다.
- 게임 설정을 변경하면 모든 물고기에 즉시 적용됩니다.
- 물고기 데이터의 기존 `distance`, `limitTime`, `point` 필드는 더 이상 사용되지 않습니다.
