# 포인트 획득시 관리자에게 푸시 전송 기능

## 구현 내용

이 기능은 사용자가 낚시 게임에서 포인트를 획득할 때 관리자에게 푸시 알림을 전송하는 기능입니다.

### 변경된 파일

1. `/app/mini-games/fishing.tsx`
   - `notifyAllAdmins` 함수 import 추가
   - `savePointToUser` 함수에 관리자 알림 전송 로직 추가

2. `/utils/send-push.ts`
   - `notifyAllAdmins` 함수 개선
     - 기존: 신규 회원 가입 알림만 전송 가능
     - 변경: 다양한 알림 유형에 대응할 수 있도록 파라미터 추가 (메시지, 제목, 화면)

### 동작 방식

1. 사용자가 낚시 게임에서 물고기를 성공적으로 잡으면 포인트가 부여됩니다.
2. 포인트가 부여될 때 `savePointToUser` 함수가 호출됩니다.
3. 이 함수는 사용자의 포인트를 저장하고, 관리자에게 푸시 알림을 전송합니다.
4. 알림에는 다음 정보가 포함됩니다:
   - 제목: "포인트 획득 알림"
   - 내용: "[사용자 이름]님이 [포인트 금액]포인트를 획득했습니다!"

### 테스트 방법

1. 관리자 계정으로 로그인하여 푸시 알림 권한이 활성화되어 있는지 확인합니다.
2. 일반 사용자 계정으로 로그인하여 낚시 게임을 진행합니다.
3. 물고기를 성공적으로 잡아 포인트를 획득합니다.
4. 관리자 기기에서 푸시 알림이 수신되는지 확인합니다.

## 주의사항

- 관리자 계정에 `isAdmin` 속성이 `true`로 설정되어 있어야 합니다.
- 관리자 기기에 `expoPushToken`이 저장되어 있어야 합니다.
- 푸시 알림을 받으려면 앱에서 알림 권한이 허용되어 있어야 합니다.
