# 물고기 기록 그룹화 기능 구현

이 문서는 물고기 기록을 물고기 이름별로 그룹화하여 포인트 합계를 표시하는 기능의 구현에 대해 설명합니다.

## 구현 내용

사용자가 잡은 물고기 기록을 개별 항목으로 표시하는 대신, 물고기 이름별로 그룹화하여 포인트 합계를 표시하도록 변경했습니다.

### 주요 변경사항

1. 그룹화된 물고기 기록을 위한 새로운 타입 정의 추가
   ```typescript
   type GroupedFishCatch = {
     fishName: string;
     totalPoints: number;
     count: number;
   };
   ```

2. 물고기 기록을 그룹화하는 로직 추가
   - 물고기 이름별로 그룹화
   - 각 그룹별 포인트 합계 계산
   - 포인트 내림차순으로 정렬

3. UI 변경
   - 물고기 이름과 잡은 개수 표시
   - 포인트 합계 표시
   - 날짜 정보 제거 (요구사항에 따라)
   - 모달 타이틀 및 메시지 업데이트

## 변경된 파일

- `/app/mini-games/ranking.tsx`
  - 그룹화된 물고기 기록 타입 정의 추가
  - fetchUserFishCatches 함수 수정하여 물고기 기록 그룹화 로직 추가
  - UI 컴포넌트 수정하여 그룹화된 물고기 기록 표시

## 사용 방법

1. 랭킹 화면에서 사용자를 선택하면 해당 사용자의 물고기 기록 요약이 표시됩니다.
2. 물고기 기록은 물고기 이름별로 그룹화되어 있으며, 각 물고기별 잡은 개수와 포인트 합계가 표시됩니다.
3. 물고기 기록은 포인트 합계 기준으로 내림차순 정렬되어 있습니다.
